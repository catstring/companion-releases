# Companion

A hand-drawn cat for your Mac desktop. It treats the edges of your app windows as platforms: it walks along them, jumps between them and naps on them.

macOS 桌面寵物：一隻手繪的貓，會把其他 App 視窗的邊緣當成平台，在上面走動、跳躍、睡覺。

**Download · 下載**：[Companion.dmg](https://github.com/catstring/companion-releases/releases/latest/download/Companion.dmg) · [made.toddmctsai.com/companion](https://made.toddmctsai.com/companion)

Requires macOS 14 or later, on Apple Silicon or Intel. Open the DMG and drag Companion into Applications.
需求：macOS 14 以上（Apple Silicon、Intel 都可以）。打開 DMG 後，把 Companion 拖進「應用程式」資料夾。

This repo only holds release downloads; the app's built-in updater (Sparkle) reads from here too.
這個 repo 只放正式版的下載檔，App 內建的自動更新（Sparkle）也從這裡讀取。
