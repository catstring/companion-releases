# Companion

macOS 桌面寵物：一隻手繪的貓，會把其他 App 視窗的邊緣當成平台，在上面走動、跳躍、睡覺。

這個 repo 只放正式版的下載檔，App 內建的自動更新（Sparkle）也從這裡讀取。

**下載最新版**：[Companion.dmg](https://github.com/catstring/companion-releases/releases/latest/download/Companion.dmg)

需求：macOS 14 以上（Apple Silicon、Intel 都可以）。打開 DMG 後，把 Companion 拖進「應用程式」資料夾。
